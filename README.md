# Kissa theme documentation

Public documentation for **Kissa**, the Shopify theme for specialty coffee roasters and cafés by STUDIO DIGI.

The site is a single `index.html`, published with Cloudflare Pages from the root of this repository (no build step).

It is generated from `theme-store/DOCUMENTATION.md` in the theme repository with `theme-store/build_docs.py`; edit the Markdown there and regenerate rather than editing `index.html` by hand.
